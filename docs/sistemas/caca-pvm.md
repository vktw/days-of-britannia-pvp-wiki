# Caça PvM

Os contratos de caça PvM oferecem uma atividade guiada para quem quer avançar
em encontros de criaturas e na progressão de Maestria.

## Onde encontrar

Há dois Hunters próximos aos bancos de **Britain** e **Cove**, em Felucca.
Fale com um deles para consultar o contrato disponível.

## Como funciona

- O contrato apresenta um objetivo de caça sorteado.
- O progresso acompanha abates PvM elegíveis do grupo indicado pelo contrato.
- Ao concluir o objetivo, entregue o contrato a um dos Hunters.
- A recompensa é uma **caixa de madeira** com uma rolagem de Loot Pack PvM.

O contrato usa a progressão de XP de Maestria PvM elegível como referência e não
cria uma tabela de loot paralela para as criaturas.

## Dicas

Consulte [Maestria PvM](pvm-mastery.md) para entender a progressão e
[Recompensas PvM](../itens/recompensas-pvm.md) para conhecer o Loot Pack. A
trilha inicial de [Achievements](achievements.md) continua sendo a melhor
introdução para personagens novos.
