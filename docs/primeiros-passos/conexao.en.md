# How to connect

!!! success "Status: Live 0.10.2"
    The official launcher configures and launches the correct client for the server.

## Official launcher

[Download DoB Launcher](https://downloads.dobshard.com/launcher/latest/DoBLauncher.exe){ .md-button .md-button--primary }

Access to the server must be done through the **official DoB Launcher**. Download the
executable using the button above, open the launcher and follow the instructions presented.

There is no need to manually configure a client or enter security data.
connection. To avoid incompatible files, keep the launcher updated and
always use the official link.

## Account

Enter an unused username and password. The account is created automatically. Account creation has no limit per IP, but the server allows a maximum of two simultaneous external connections via the same address.

Never share your password. The team doesn't need it for support.
