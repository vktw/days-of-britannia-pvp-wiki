# Death and recovery

!!! success "Status: Live 0.9.8"
    This flow applies to deaths outside the Arena.

When you die, choose how to return to [Ocllo Safe Haven](../mundo/ocllo.md):

1. Resurrect immediately in Ocllo; remaining items stay on the corpse.
2. Wait 60 seconds and return to Ocllo with the remaining corpse items recovered.
3. Wait for help for up to five minutes; at the end of the wait, return to Ocllo with the remaining corpse items recovered.

Newcomers use the automatic return described in [Newcomer and protection](newcomer.md).
